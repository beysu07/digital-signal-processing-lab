# Digital Signal Processing Laboratory

This repository contains MATLAB-based laboratory studies completed for the Digital Signal Processing course.

## Course Reference

Li Tan, *Digital Signal Processing: Fundamentals and Applications*

## Labs

### Lab 1: Sampling and Quantization

This lab focuses on the sampling and quantization of a sinusoidal signal using MATLAB.

The analyzed signal is:

```math
x(t) = 6cos(2000πt)

Main topics:

* Sampling of sinusoidal signals
* Nyquist sampling criterion
* Comparison of different sampling frequencies
* Quantization with different bit depths
* Quantization error analysis
* Audio signal quantization using train.mat

Lab 2: Digital Signal Generation and Spectral Analysis

This lab includes generating Gaussian white noise and sinusoidal signals using MATLAB.

Main topics:

* White noise generation
* Sum and product of sinusoidal signals
* FFT-based spectral analysis
* Audio waveform analysis
* Frequency resolution
* Bandwidth analysis

Lab 3: Digital Filters

This lab focuses on digital filter design and implementation.

Main topics:

* Difference equations
* Transfer functions
* Frequency response using freqz
* FIR and IIR filter design
* Pre-emphasis filtering
* Audio filtering
* ECG noise filtering

Tools Used

* MATLAB
* FFT
* FIR/IIR Filters
* Signal Processing
* Audio Analysis

Project Purpose

The purpose of this laboratory work is to understand the fundamentals of digital signal processing through MATLAB simulations and practical signal analysis.

The experiments demonstrate how digital signals are generated, sampled, quantized, transformed into the frequency domain, and filtered using FIR and IIR filters.
